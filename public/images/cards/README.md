# 홈 큐레이션 카드 사진 (Time Out 식 대형 카드)

`components/home/CuratedGridSection.tsx` 가 이 폴더의 파일을 파일명 규칙으로 자동 참조합니다. 파일을 두면 즉시 반영, 없으면 카테고리 색 gradient 로 자동 폴백(빈 카드 금지).

## 파일명 규칙 (6종 · 정확히 이 이름)

| 카테고리 | 파일 경로 |
|---|---|
| walk (산책)       | `public/images/cards/card-walk.jpg` |
| food (미식)       | `public/images/cards/card-food.jpg` |
| culture (문화)    | `public/images/cards/card-culture.jpg` |
| kculture (K컬처)  | `public/images/cards/card-kculture.jpg` |
| history (역사)    | `public/images/cards/card-history.jpg` |
| family (가족·체험) | `public/images/cards/card-family.jpg` |

## 사진 규격

- **비율**: 4 : 3 (가로 : 세로)
- **해상도**: 최소 1200 × 900, 권장 1600 × 1200 이상
- **포맷**: `.jpg` (표준) · 필요 시 `.webp` 는 별도 오더로 확장
- **파일 크기**: 개당 400 KB 이하 권장 (Next.js Image 최적화가 이후 압축·리사이즈)
- **컬러**: sRGB · 후보정 자유

## 구도 규격 (오버레이 대응)

카드 위에 다음 요소가 **얹혀지므로** 사진 자체는 그 자리를 비워 두거나 밝게 유지:

- **중앙**: 폭 55 % 대형 엠블럼(카테고리 색 원형 배지) 이 얹힘 → 중앙은 피사체를 살짝 비켜서 배치하거나 배경이 잔잔한 프레임 권장
- **하단 40 %**: 검정 스크림(투명→0.7) 이 씌워져 텍스트(카테고리 레이블 + "고양 BEST N선") 가 흰색으로 얹힘 → **피사체·주요 정보는 상단 60 % 안에**, 하단은 스크림 얹혀도 인상 안 깨질 배경성 톤이 좋음
- 필요 시 상단 밝은 노출 / 하단 어둠 유도 (기본 스크림이 어두우니 하단이 이미 어두운 사진은 대비 손실 주의)

## 접근성

카드 이미지의 `alt` 는 현재 빈 문자열(장식 이미지 취급) 로 처리됨. 헤드라인·카테고리 레이블 텍스트가 이미 스크린리더에 카드 내용을 전달하기 때문. 사진에 사진 자체 설명이 반드시 필요한 경우(예: 특정 인물·장소가 정보의 핵심) 별도 오더로 alt 계약 개편.

## 저작권

각 파일은 상업적 이용 가능 라이선스(자체 촬영·유료 라이선스·CC0 등) 여야 합니다. 라이선스 근거를 파일과 함께 별도 문서에 기록해 두세요.

## 반영 확인

파일을 넣은 뒤:
1. `npm run dev` 로 로컬 확인 (Next.js Image 최적화 즉시 적용)
2. 커밋·푸시 → Vercel 프리뷰 배포에서 자동 반영

파일이 없거나 로드 실패 시(예: 손상된 파일) 카드는 카테고리 색 gradient 로 폴백하며, 엠블럼·헤드라인은 그대로 노출됩니다.
