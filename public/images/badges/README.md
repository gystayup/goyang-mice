# 카드 중앙 배지 이미지 (AI 생성 · 투명 PNG)

> **압축 상태**: 현재 커밋된 6장은 `sharp` 로 1024×1024 · palette PNG 로 최적화된 압축본(각 ~400KB, 총 2.38MB). 원본 고해상도 파일은 별도 보관.


`components/home/CuratedGridSection.tsx` 가 카드 중앙 대형 배지를 이 폴더의 파일로 자동 렌더합니다. 파일이 있으면 이미지로, 없으면 자체 SVG 엠블럼(`components/emblem/Emblem.tsx` size=L) 로 자동 폴백. **빈 자리 금지**.

`public/images/cards/` (배경 사진) 와는 **독립적** 으로 폴백 판정이 이뤄지므로:
- 사진 O · 배지 O → 완전 완성형
- 사진 O · 배지 X → 사진 배경 위 SVG 엠블럼 (기존 상태)
- 사진 X · 배지 O → 카테고리 색 gradient 위 이미지 배지
- 사진 X · 배지 X → gradient 위 SVG 엠블럼 (최소 폴백)

## 이미지 규격

- **포맷**: `.png` (표준) — **투명 배경 필수** (알파 채널)
- **비율**: 1 : 1 (정사각)
- **해상도**: 최소 **512 × 512**, 권장 **1024 × 1024** (retina 대응)
- **파일 크기**: 개당 300 KB 이하 권장 (Next.js Image 최적화가 후처리)
- **컬러**: sRGB · 카테고리 색 팔레트 근접 권장 (엠블럼 컬러와 문맥 통일):
  - walk `#00A651` / food `#FF7A00` / culture `#7C3AED`
  - kculture `#F5258C` / history `#1D4ED8` / family `#06B6D4`

## 배치 규격 (카드 오버레이 대응)

카드에서 배지는 **카드 폭의 55%** 로 중앙에 얹힘. AI 생성 시:

- **캔버스 여백**: 이미지 안쪽 요소가 캔버스 가장자리에서 최소 6% 여백 (배지가 완전 원형이어도 잘리지 않게)
- **하단 텍스트 회피**: 카드 하단 40% 는 검정 스크림 + 흰색 헤드라인이 얹히므로, 배지 이미지 자체가 시각적 상단·중앙에 무게 중심을 두는 게 좋음 (하단에 미세 텍스트/장식이 있으면 헤드라인과 충돌 가능)
- **원형 배지 권장**: SVG 엠블럼과 일관성 위해 원형 프레임 유지, 상단 아크 텍스트/리본 유지는 자유
- **광원**: 자체 그림자·글로우 허용하나 카드 사진 위에 얹히므로 아주 강한 drop shadow 는 지양

## AI 생성 프롬프트 힌트 (참고)

각 카테고리별로 이미 정의된 5레이어 규격(외곽 링·크림 원·상단 아크 텍스트·중앙 아이콘·하단 리본) 을 살리고 싶다면 프롬프트에 반영:

- "GOYANG BEST" 상단 아크 텍스트, 하단 리본에 카테고리명, 중앙에 고양이 심볼, 카테고리 컬러(walk = green 등), 크림 배경(#FFF8EF), 원형 배지, 투명 PNG, 정사각, 1024px

정식 캐릭터 아트가 준비되면 이 이미지들만 교체하면 되고, 컴포넌트 코드는 손대지 않아도 됨.

## 접근성

배지 이미지의 `alt` 는 빈 문자열(장식 이미지 취급). 카테고리 정보는 헤드라인/레이블 텍스트가 스크린리더에 전달. 배지가 유일한 정보 전달원이 될 경우 별도 오더로 alt 계약 개편.

## 저작권

각 파일은 상업적 이용 가능 라이선스여야 합니다. AI 생성물의 경우 사용 모델의 상업 이용 약관을 확인.

## 반영 확인

파일을 넣은 뒤:
1. `npm run dev` → `http://localhost:3000/ko` 카드에서 배지 이미지로 즉시 대체 확인
2. 커밋·푸시 → Vercel 프리뷰 자동 반영
3. 로드 실패(손상·미존재) 시 자동으로 SVG 엠블럼 폴백 → 빈 자리 없음
